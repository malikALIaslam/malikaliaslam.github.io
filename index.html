SQL VIEW PROJECT ↗
ADVANCED SQL

Pakistan E-Commerce Sales Analysis

An end-to-end Advanced SQL data analysis project based on Pakistan e-commerce transaction data. The project explores sales performance, customer behavior, product and category performance, payment methods, order status, discounts, and monthly revenue trends using MySQL. Advanced SQL techniques including CTEs, subqueries, window functions, LAG(), RANK(), DENSE_RANK(), running totals, and revenue contribution analysis were used to generate meaningful business insights.
